# The Drinking Cog 🪶🥃

A **cinematic, physics-accurate, sensory masterpiece** simulation of the classic Drinking Bird heat engine toy.

## ✨ Now Even More Awesome (latest commit)
- **Ultra-realistic SVG drinking motion** — 48° deep tilt, momentum bob, sloshing liquid
- **Rising bubbles + ripples** in the glass when beak dips
- **Beak splash + droplet particles**
- **Eye blink & alive expression**
- **Full synced sound effects** — gulp, fizzing bubbles, ambient trickle (toggle on/off)
- **Temperature gauge** — real physics: hotter = faster cycles, more bubbles, higher pitch sound
- Cinematic neon UI with glassmorphic panels
- 60fps buttery smooth on mobile & desktop
- Educational phase facts + science behind the cog

## Features
- Animated SVG Drinking Bird that **visibly AND audibly drinks**
- Real-time cycle counter
- Adjustable speed + temperature controls
- Pause / Start / Reset
- Sound toggle (browser-safe)

## How to Run

```bash
pnpm install
pnpm dev
```

Visit https://thedrinkingcog.vercel.app to watch the bird **send it** endlessly!

Built as a Next.js App Router project with Tailwind + SVG animations.
