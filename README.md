# The Drinking Cog 🪶

A fun, interactive simulation of the classic **Drinking Bird** heat engine toy.

## Features
- Animated SVG Drinking Bird that bobs and dips
- Real-time cycle counter
- Adjustable speed control
- Pause / Start controls
- Educational explanation

## How to Run

```bash
pnpm install
pnpm dev
```

Visit http://localhost:3000 to watch the bird drink endlessly!

Built as a Next.js App Router project.
